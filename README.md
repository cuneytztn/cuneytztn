# Hi 👋, I'm Cüneyt Öztan
## Senior Full-Stack Developer

I'm a Full-Stack Developer based in Istanbul, Turkey, building real-time, data-intensive web applications with ASP.NET Core and React + TypeScript. Lately I've been spending a lot of my time on AI-assisted development: building multi-agent workflows, MCP servers and tools that put coding agents to work.

### 🚀 What I Do
- Build full-stack web applications with ASP.NET Core (MVC & Web API) and React + TypeScript
- Design real-time systems with SignalR and event-driven architectures with Kafka
- Work with MongoDB, Redis caching and SQL Server for scalable data layers
- Manage complex client state and data fetching with Redux Toolkit & RTK Query
- Refactor legacy codebases toward Clean Architecture
- Implement secure authentication and authorization flows

### 🤖 AI & Agentic Development
- **Agent orchestration:** building a local orchestrator app (Node + React/TS) that manages per-project task lists and dispatches tasks such as start, test and review to coding agents
- **Multi-agent development:** designed a Claude Code workflow with an architect agent for scaffolding, parallel feature agents and a reviewer agent, coordinated through orchestrator and per-module `CLAUDE.md` files
- **MCP servers:** developing Model Context Protocol servers in Python (MCP SDK, FastAPI) that let AI assistants carry out real-world transactions
- **AI tooling:** day-to-day use of Claude Code with MCP servers (Memory, Context7, Sequential Thinking), custom skills and plugins
